2. LOCAL-FIRST ARCHITECTURE

Momentum is a local-first application. All data remains on your device.

2.1 Data Storage

All application data is stored in the following directory on your device:

~/.meks-apps/momentum/

This directory contains:
- config.json (application configuration)
- Database files (task data)
- Any user-generated content

2.2 No Automatic Data Transmission

The Application does not transmit user data to external servers by default. No analytics, telemetry, or usage data is sent automatically.

2.3 Local-Only Operation

The Application functions fully without an internet connection. Core features (task management, data storage, UI) work offline.

3. PERMISSIONS

The Application requests the following permissions:

3.1 Read/Write File System Access

3.2 Browser Access

Required to open external links (support pages, documentation, GitHub repository) in your default web browser. This permission is only used when you click a link that opens an external page.
